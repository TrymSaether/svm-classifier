\section{Numerical Methods}
\label{chap:numerical_methods}
\vspace{-0.4cm}
\subsection{Gradient Descent for Primal SVM}
We are now interested in implementing a numerical solution to the primal SVM problem. Since the objective is convex, gradient-based optimization methods can be used to reliably find a global minimum.

To handle non-separable data, we use a soft-margin formulation, which allows some margin violations at a cost controlled by a regularization parameter. This cost is incorporated using a loss function, e.g., the hinge loss, which penalizes misclassified points.
However the hinge loss function is non-smooth, so we instead use a smooth approximation, specifically the logistic loss:
\begin{align*}
    \ell(t) = \log(1 + e^{-t}) 
\end{align*}
which penalizes misclassified points, and is differentiable. 
The gradient is computed from the contributions of all training points, weighted by how much they violate the margin, and scaled by the regularization term.
Using this gradient, we update the weights iteratively in the direction of steepest descent until convergence to an optimal solution.

\subsection{Projected Gradient Descent for Dual SVM}
We are now interested in implementing a solution to the dual problem numerically. 
The reason we are interested in the dual problem numerically is that it allows us to use different kernels, to classify non-linearly which may give us a more accurate classification.
We solved the dual SVM problem using projected gradient descent, where each update projects the gradient step back onto the feasible set defined by the constraints.
The projection was implemented by converting the problem into a constrained minimization problem given by:
\begin{align*}
\pi_{\Omega}(\symbf{\beta}) := \min_{\symbf{\alpha} \in \mathbb{R}^M} \frac{1}{2} \|\symbf{\alpha} - \symbf{\beta}\|_2^2 \quad \text{s.t.} \quad
\begin{cases}
\symbf{y}^\top \symbf{\alpha} = 0 \\
\symbf{0}_M \leq \symbf{\alpha} \leq C\symbf{1}_M
\end{cases}
\end{align*}
This way we can use the Lagrangian method with one lagrange multiplier, $\lambda$, and solve the projection efficiently via bisection.

\subsubsection{Step Length Selection}
To determine appropriate step lengths in both gradient descent methods, we implemented the \emph{Barzilai-Borwein (BB) method}, which dynamically estimates optimal step sizes based on information from previous iterations.
When the BB method produced unusable step lengths (e.g., negative or excessively large values), we defaulted to a conservative fixed step size to ensure algorithm stability.
In some cases where the step length was not satisfactory it would be necessary to perform a line search. This does come at a higher computational cost.
So to avoid unnecessary line searches, we tracked a reference function value, $f_{ref}$, and only triggered a line search when the objective increased beyond this threshold.
If the function hadn't improved after a set number of steps, we updated the reference and potentially performed a line search.
This approach gave fast convergence while keeping computational cost low.
